# Website Instalasi Gas LPG

Situs statis: `index.html`, `styles.css`, `script.js`. Tidak perlu build.

## Ganti data
- Nomor WA/telepon: cari `6285103542848` dan `0851-0354-2848` di `index.html`.
- Foto proyek: taruh di folder `images/`, lalu ganti tiap `<div class="ph">Foto menyusul</div>` dengan
  `<img src="images/nama-foto.jpg" alt="Deskripsi foto" loading="lazy">`.

## Deploy
- **Vercel:** Import repo di vercel.com → Framework "Other" → Deploy.
- **GitHub Pages:** Push ke GitHub → Settings → Pages → Branch `main`, folder `/ (root)`.

Setelah online, isi link situs di profil Google Bisnis (kolom "Situs web").
